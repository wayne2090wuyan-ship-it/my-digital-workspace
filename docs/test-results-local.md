## 2026-10-23 备份重点浏览器回归

先针对最后修改运行过重点回归；本轮完整回归后，再运行 `MDW_BROWSER_FOCUS=backup node tests/browser.cjs`。5 组真实 Chromium 检查全部通过：

1. 两条记录在不同模块使用相同 id 可以预览和恢复；删除任务不会删除同 id 的生活记录。
2. 同一模块内的相同 id 仍是冲突，包含一条冲突的批量恢复不会部分新增。
3. UTF-8 JSON 文件恰好为 8 MiB 可读取和预览；超过 1 字节即拒绝，验证 `File.text()` 没有被调用。
4. 本地受控云 provider 返回大于 4 MiB、仍小于 8 MiB 的虚构内容时，界面明确失败且无下载；正常大小的导出可下载并解析。此处不代表真实云导出已测通过。
5. 本轮无 pageerror、无外网请求，无任何云资源操作。

唯一性约定为“当前用户 + 模块 entity + 记录 id”，演示仓储和恢复校验不再把跨模块相同 id 误判成冲突。文件读取与演示导出上限 8 MiB、云导出上限 4 MiB，均按 UTF-8 字节而非 JavaScript 字符数。云恢复另有 40 条及完整请求 128 KiB 上限；大备份不会自动拆成部分导入。

## 验收中发现并修复

- 隐藏的健身时长字段仍参与其他模块编辑校验，导致保存无响应：现已禁用不适用字段。
- 退出后隐私遮蔽 class 残留：统一清理，成功刷新后解除遮蔽。
- 登录/首次数据加载失败可能保留旧界面：进入前清空，失败继续锁定。
- 新建请求传递 `version: undefined`：改为仅更新请求附带版本。
- 导入文件异步读取与退出存在竞态：通过会话 generation 和文件读取序号检查，退出清空文件控件及预览。
- 云恢复一次预览生成一个 UUID，失败直接重试保留同 UUID；退出、取消或重新选文件清除旧请求编号。恢复期间禁用文件选择，避免替换正在提交的备份。
- 桌面固定侧栏锚点和当日日程长列表：明确 top/left，日程列表可滚动。
