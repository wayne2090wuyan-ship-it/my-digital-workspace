# CloudBase 试用环境验收

日期：2026-10-23。仅使用独立的虚构测试账号和数据。原首页、dashboard、assets 和原 README 均保留。

## 已实际部署

- 上海 CloudBase 体验环境；传统文档型数据库，不使用 SQL RLS。
- 事件函数 `mdwPrivateApi`，Node.js 20.19；统一 SDK 3.10.3，运行时签名依赖随包部署。
- `mdw_records`、`mdw_authz`、`mdw_imports` 均为 ADMINONLY，浏览器不能直接读写。
- 函数默认禁止调用，仅业务函数允许非匿名登录用户进入；函数再逐次校验不可由普通用户编辑的授权名单。
- 可信身份来自平台运行上下文；忽略 event 中的 userInfo/tcbContext 元数据，拒绝业务请求中的 uid、owner_id 等额外字段。
- 所有记录以可信用户编号限定查询、创建、修改、删除；修改和删除校验版本。恢复为事务内二次授权、仅新增、全部成功或全部回滚。

## 实际云端证据

当前 Mac 上 Chromium 显式 `--no-proxy-server`，本地前端直接访问真实上海云环境。

15 组集成检查全部通过：真实密码登录、无登录拒绝、已登录但未获授权拒绝、六模块 CRUD、两个独立浏览器会话同步、跨账号读改删拒绝、伪造归属拒绝、直连数据库和授权表读写拒绝、重复创建幂等、并发版本竞争仅一个成功、导出不带身份凭据、真实浏览器断网不虚报成功、退出后拒绝调用/重登恢复数据、事务恢复与重试幂等/冲突回滚、删除虚构记录。

9 组真实前端联动检查通过：官方 SDK 登录、六模块表单保存、390px 独立会话刷新同步、编辑同步、云端导出下载、六模块界面删除、服务端撤销名单后已登录页面锁定、退出清空记录、无 pageerror。曾出现测试超时，原因是测试未展开“所有独立日程”，实际保存成功；修正测试后通过。

本地隔离测试及截图见 [本地验收记录](test-results-local.md)。本地 mock 与真实云测试分别记录，不能互相替代。

## 限制与运维

- 这证明当前 Mac 网络的直接访问。未实测真实 iPhone Safari、iPhone 蜂窝、其他运营商或长期网络稳定性。手机尺寸浏览器不是 iPhone。
- 已测试退出和授权撤销；未等待自然 JWT 过期的完整生命周期。令牌仅在页面内存保存，刷新需重登；回到页面与服务请求会重新检查会话/授权。
- 网关直接抛出的过期/鉴权异常也会锁定并清空会话；已覆盖官方 CHECK_LOGIN_FAILED、ACCESS_TOKEN_EXPIRED 等错误码回归，依据 [官方错误码](https://docs.cloudbase.net/error-code/basic)。自然过期长周期仍未实测。
- 设置中的时区仅当前页面有效；跨设备同步的是六模块数据，不含显示偏好。
- 云端导出最多 2000 条、4 MiB；单模块列表最多 1000 条，超过明确报错，不静默截断。
- 云端恢复最多 40 条且完整请求 128 KiB，仅新增，不覆盖已有记录、不自动拆批。更大备份需后续开发受控迁移流程。导出不是自动云备份。
- 体验套餐到期日 2027-04-22 23:59:59；自动续费和超额计费均关闭，不能保证到期后继续免费。未开通收费日志、付费备份或其他收费服务。
- 正式长期使用前应评估续期/付费选择、独立备份和实际手机网络。本版本适合有上述边界的个人试用，不保存论文全文或高敏感资料。
- 页面代码和环境编号可公开；授权名单、记录、账号、会话和管理凭据不在仓库。不能把前端域名名单当成权限边界。

## 回滚

原始演示版本为 `61f4e611c23f3229949f9d66ac162ba9cae00216`。新增私人入口位于 `private/`；原网址不变。紧急锁定可将 `private/config.public.js` 的 enabled 改为 false 并发布；真正撤销访问必须在服务端禁用该用户的 mdw_authz.enabled。前端锁定不能撤回已发出的令牌或替代服务端授权。

后台回滚应重新部署已验证版本；保留数据，禁止通过删除环境恢复程序。数据库模式、权限和必要命令见 [运维说明](cloudbase-operations.md)。Supabase 项目未删除或修改。
